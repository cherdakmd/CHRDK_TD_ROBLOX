# Чек-лист проверки в Roblox Studio

## Запуск

- [ ] Открыть `release/CHRDK_Rubezh.rbxlx` или подключить Rojo.
- [ ] Нажать Play; в Output должно появиться `[РУБЕЖ] Server ready`.
- [ ] Карта, портал, ядро, 18 площадок и HUD создаются без ошибок.
- [ ] Обучение открывается один раз за вход и закрывается кнопкой/Esc.

## Соло-цикл

- [ ] Стартовое золото 600.
- [ ] Выбор площадки → выбор башни строит башню и списывает цену.
- [ ] Повторное строительство на занятой площадке не списывает золото.
- [ ] Улучшение до IV работает, после IV кнопка показывает максимум.
- [ ] Продажа возвращает 70% строительства и улучшений.
- [ ] Приоритеты Первый/Сильный/Ближний меняют поведение.
- [ ] Мортира не стреляет по призракам; Страж/Криомант/Тесла стреляют.
- [ ] Метеор требует точку на карте, Стужа замедляет всех.
- [ ] Прорыв врага уменьшает ядро; при 0 HP появляется поражение.
- [ ] После победы/поражения работает голосование за новый матч и автоматический рестарт.

## Кооператив

- [ ] Studio → Test → Start Server с 4 игроками.
- [ ] Пятый игрок не допускается; в настройках опубликованного места Max Players = 4.
- [ ] Нельзя улучшать/продавать чужую башню.
- [ ] Награда за врага делится по урону, а не достаётся только добившему.
- [ ] Готовность всех ускоряет старт; отмена готовности возвращает задержку.
- [ ] 2× включается только большинством; при выходе игроков большинство пересчитывается.
- [ ] Досрочная волна и рестарт требуют большинства.
- [ ] Опоздавший игрок получает компенсационное золото и может строить.
- [ ] Выход владельца не ломает его оставшуюся башню и не даёт другим её продать.

## Мобильные и камера

- [ ] Касание выбирает площадку, перетаскивание двигает камеру, щипок меняет масштаб.
- [ ] Карточки башен, способности и инспектор не перекрывают критичные кнопки.
- [ ] Метеор выбирается кнопкой и подтверждается касанием карты.
- [ ] R сбрасывает камеру на ПК; на мобильном мини-карта помогает перемещаться.
- [ ] Текст читается на маленьком экране; длинные имена не ломают панель отряда.

## Сохранения

- [ ] В опубликованном месте включён API-доступ для проверки из Studio.
- [ ] После волны/матча меняются XP, уровень, победы, лучшая волна.
- [ ] Выход и повторный вход сохраняют постоянный прогресс.
- [ ] Золото и башни матча НЕ переносятся в новый матч.
- [ ] При недоступном DataStore игрок видит предупреждение, а старые данные не перезаписываются.
- [ ] Быстрый переход между серверами не приводит к потере прогресса благодаря session-lock.

## Производительность

- [ ] 20-я волна с боссом и 4 игроками не вызывает заметных просадок.
- [ ] Эффекты не накапливаются бесконечно.
- [ ] После рестарта старые враги/башни/эффекты удалены.
- [ ] В Output нет повторяющихся ошибок RemoteEvent, PivotTo, UI или DataStore.
